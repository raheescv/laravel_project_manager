Top up — premium directions

Three ways to lift TopupView.vue. Same content, same tokens, same Font Awesome 4.3 set — only the arrangement and the weight of the iconography differ. Pick one and I'll port it.

Nothing here invents a colour. Every surface, ink and accent below is an existing token from parent_portal/src/assets/app.css, so the school's pinned accent keeps driving the whole screen and dark mode comes for free. Toggle the theme above to check both.
