Theme
Two body layouts, same Premium shell. Both share the themed hero, footer and tokens of the Branch / Employee / Voucher modals. Both are live — type an amount, pick a category, click a date chip and watch the posting preview update.
  • A · Ledger — three numbered panels on a 12-col grid. Closest to the existing Premium modals.
  • B · Flow (recommended for “ultra user-friendly”) — the amount is the headline, then one full-width row per question in the order people think: for what → paid from → when → who → reference → note. Big targets, zero clutter, reads like a receipt.
Shared upgrades: currency code on the amount, Today / Yesterday chips, recently-used category chips, live character counters (30 / 100 limits already enforced server-side), inline field errors, and a plain-English “what will be recorded” line with the Dr / Cr legs. The third card shows B in edit mode with validation errors.
