Where it is chosen — Settings → Sale Settings

The preset is saved as Configuration key pos_color_preset by the Sale Configuration form, passed to the POS by SaleController, and stamped on the POS root as data-pos-preset. Every modal inherits it because they all render inside that root.

Modals — same tokens, same chrome

Each POS modal now uses one shell: primary header bar, panel body, neutral footer with a ghost + primary button pair. They follow the preset and the dark toggle above.

What else changes with the palette

1. Borders. Every field today is border-2 in its own colour (indigo customer, emerald mobile, purple employee, orange sale type). They become 1px hairlines in one neutral; colour appears only on focus.
2. Gradients. The three blurred blobs behind the control card, the 3-stop gradients on every button and the from-emerald via-teal to-cyan sidebar header collapse to flat surfaces + one very soft ambient glow.
3. Category rows. Favorites (rose→purple), All Products (emerald→cyan) and each category (violet→indigo) all used different gradients when selected. Now: selected = solid primary, Favorites = the accent.
4. Cart. Indigo/violet gradients become the same neutral panel; the quantity badge is the only primary block.
5. Dark mode. The current screen has none — hardcoded bg-white, text-slate-800. Tokenising is what makes the dark column above possible, if you want it.
