What changed. The branch form now follows the same Premium system as the Employee (.empx) and General Voucher (.gvx) modals: a themed hero, panelled sections, icon-led fields, and switch rows instead of the bare checkbox. Exclude from Showcase is the new flag — when it is on, the branch is dropped from GET /api/v1/branches, so the showcase app and website stop listing it.
