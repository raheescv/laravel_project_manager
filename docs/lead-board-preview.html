Preview notes · not part of the UI

New link

/property/lead/board gated on property lead.view. Added to the sidebar under Leads → "Lead Board", with a List · Board · Calendar switch on all three pages. Moving a card needs property lead.edit.

Drag = save

A drop saves only the status through the existing UpdateAction, so the lead's Audit tab records it. Undo is just a second move. On phones, tap a card and use the "Move to" chips.

Built for 25k leads

Column counts come from one grouped query. Each column loads 20 cards, with "Load 20 more" for the rest. Filters match the list page (dates, type, project, salesman, source, search).

Messy status values

Values that aren't real statuses (Low Budged, Fallow Up, Priority, blank) go to "Unmapped", and dragging a card out fixes it. Case and space variants like Dead lead or Low Budget␠ join their real column.
