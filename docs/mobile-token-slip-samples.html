Bold Block

  • The number sits on a solid brand-colour block, so it reads from across the counter.
  • Counters are big tap tiles that show each counter's next number. One tap issues for that counter.
  • On the slip, the number prints in a solid black box, the strongest look on paper. It uses more thermal ink per slip.
  • The icon-only Close and Reprint buttons keep "New Token" dominant.

One settings screen, live preview on top

  • The mini slip at the top redraws as you change any value.
  • Number: prefix, digits (zero-pad), start, device tag (so two kiosks never print the same number), reset daily/never.
  • Counters: a list of name + prefix, each with its own sequence. With none set up, the screen shows a single number stream.
  • Slip: number size M/L/XL, logo, header/footer EN + AR, auto-print.
  • "Reset counter" sits at the bottom behind a confirm dialog. It isn't shown in this mock-up.
  • The logo and company name come from the existing Print Settings, so nothing is entered twice.
